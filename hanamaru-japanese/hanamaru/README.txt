하나마루 일본어 — 아이폰 설치 방법

이 폴더의 파일 6개(index.html, manifest.webmanifest, sw.js, icon-180.png, icon-192.png, icon-512.png)를
HTTPS 정적 호스팅에 그대로 올리면 됩니다. 예: GitHub Pages, Netlify, Cloudflare Pages.

[GitHub Pages 예시]
1. GitHub에서 새 저장소를 만들고 이 파일들을 업로드합니다.
2. 저장소 Settings → Pages → Branch를 main / (root)로 지정하고 저장합니다.
3. 잠시 뒤 표시되는 주소(https://아이디.github.io/저장소이름/)를 아이폰 Safari로 엽니다.
4. 공유 버튼 → '홈 화면에 추가'를 누르면 앱 아이콘이 생깁니다.

한 번 열고 나면 인터넷 없이도 실행됩니다. 학습 기록은 아이폰에 저장됩니다.
